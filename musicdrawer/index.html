Music Drawer Uploader

Bu uygulama yalnızca sahibinin kendi YouTube kanalı music drawer için video yüklemek, kanalı yönetmek ve kanal istatistiklerini okumak amacıyla kullanılır. / This app is used only to upload and manage videos and read analytics for the owner's own YouTube channel.

Gizlilik Politikası / Privacy Policy

Uygulama YouTube Data API ve YouTube Analytics API üzerinden yalnızca sahibinin kendi kanal verilerine erişir. Veriler üçüncü kişilerle paylaşılmaz veya satılmaz; erişim anahtarları gizli tutulur. Uygulamanın Google kullanıcı verilerini kullanımı Google API Services User Data Policy'ye uygundur. Erişim https://myaccount.google.com/permissions adresinden kaldırılabilir. / The app accesses only the owner's own channel data. Data is not shared or sold.

Kullanım Şartları / Terms

Uygulama yalnızca kanal sahibinin kişisel kullanımı içindir. / For the channel owner's personal use only.
